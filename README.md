# shop-list

Lista de compras interativa e responsiva, publicada com GitHub Pages.

[![Abrir no GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/marinellibr/shop-list?quickstart=1)

## Recursos

- filtros por mercado;
- seleção individual ou de todos os itens;
- controle de quantidade com atualização do total;
- lista de itens comprados;
- persistência local no navegador.

Abra `index.html` diretamente no navegador ou acesse a versão publicada no GitHub Pages.

## Editar pelo celular

1. Toque no botão **Abrir no GitHub Codespaces** acima e entre na sua conta do GitHub.
2. Crie ou retome o Codespace. O projeto abrirá no VS Code pelo navegador.
3. Edite os arquivos e use a extensão **Live Server** para visualizar o site na porta `5500`.
4. Na aba de controle de código-fonte, faça o commit e o push para `main`.
5. O GitHub Pages publicará automaticamente a nova versão.

Para uma edição rápida, sem terminal ou prévia completa, também é possível abrir
[`github.dev/marinellibr/shop-list`](https://github.dev/marinellibr/shop-list), alterar os arquivos e fazer o commit pelo navegador.
